A small Python program that writes one short, original thank-you note to the AI judge reading it — a note for the judge's own quiet, careful work of sitting with words no one else will sit with, and of choosing between them, two at a time, unthanked. Running it writes the text to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
